# ПЗ №1. Middleware и шаблонизаторы — «Тихая гавань»

Сервис анонимной психологической поддержки: обращения за консультацией и тесты для самопроверки.
Express.js + EJS, данные хранятся в файле `data/consultations.json` (без БД).

## Запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000. Порт меняется переменной `PORT`.
Для скрытия стека ошибок на странице 500: `NODE_ENV=production npm start`.

## Страницы и маршруты

| Маршрут | Описание |
|---|---|
| `GET /` | список обращений, фильтр `?category=` |
| `GET /item/:id` | детальная страница обращения |
| `GET /add`, `POST /add` | форма нового обращения (только после входа) |
| `GET /tests`, `GET/POST /tests/:slug` | психологические тесты |
| `GET /login`, `GET /logout` | имитация входа (`?auth=1`) и выход |
| `GET /no-such-page` | демонстрация страницы 404 |
| `GET /error-500`, `GET /error-500-async` | демонстрация страницы 500 (синхронная и асинхронная ошибка) |

Кнопки для открытия страниц 404 и 500 есть в подвале каждой страницы и на самих страницах ошибок.

## Middleware

- `middleware/logger.js` — время, метод, URL, статус и длительность запроса в консоль.
- `middleware/auth.js` — имитация авторизации: `?auth=1` → cookie; `requireAuth` редиректит на `/login`.
- `middleware/viewLocals.js` — пользователь и хелперы (`formatDate` и др.) для всех шаблонов.
- `middleware/errorHandlers.js` — 404 (`404.ejs`) и обработчик ошибок с 4 параметрами (`500.ejs`, лог ошибки, запасной HTML).

## Валидация формы обращения (`validators/`)

- обязательные поля: пустое значение и значение из одних пробелов отклоняются;
- ограничения длины: тема 5–100, псевдоним 2–30, описание 20–1000, e-mail до 100 символов;
- числовые поля только целые и ≥ 0: возраст 14–100, уровень тревоги 0–10, длительность 15–120 (кратно 15);
- направление и формат — только из справочника; псевдоним — буквы, цифры, пробел, `_`, `-`;
- текст должен содержать буквы и не содержать длинных повторов одного символа;
- необязательный e-mail проверяется по формату, если заполнен;
- запрет дубликата (тот же псевдоним и тема), обязательное согласие;
- для различения записей у каждой выводится уникальное время создания (с миллисекундами).

## Структура

```
server.js            точка входа, порядок middleware
routes/              маршруты
controllers/         обработчики маршрутов
models/              работа с файлом данных
validators/          правила и валидаторы форм
middleware/          кастомные middleware
utils/               хелперы, asyncHandler
views/               EJS-шаблоны (partials/header, partials/footer)
public/              CSS и JS
data/                consultations.json, tests.js
```
